# Architecture Decision Records

This directory contains Architecture Decision Records for significant technical
and architectural choices made throughout the project.

Each accepted ADR documents:

- the decision context
- the selected approach
- the consequences of the decision
- the alternatives considered
- the decision status

ADRs preserve the reasoning behind important choices without turning the current
architecture documentation into a historical discussion log.

## Naming convention

Architecture Decision Records use the following format:

```text
ADR-NNN-short-decision-title.md
